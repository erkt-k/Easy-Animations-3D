# Easy Animations 3D 
## Full Disclosure!
The 3D models used to show the animations and in the Test Scene are from [Kenney Assets](https://kenney.nl/assets)

The animations use DOTween, this is an asset to add them without writing all the code necessary.
## Description  
This is a small asset to install animations in your 3D Unity project more easily!
Right now it's in a preparations stage but the goal is to have the basic animations as addable components so adding them won't require adding a bunch of boiler plate code instead just an animation call and you can setup the details in the inspector.
