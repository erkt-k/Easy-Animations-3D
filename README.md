# Easy Animations 3D 
## Description  
This is a small asset to install animations in your 3D Unity project more easily!
Right now it's in a preparations stage but the goal is to have the basic animations as addable components so adding them won't require adding a bunch of boiler plate code instead just a static animation call and you can setup the details in the inspector.

If you're interested you can follow the progress!
